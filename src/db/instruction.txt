как запустить бд на вашем компе:

1) откройте pgadmin4
2) создайте бд c именем funeral_services
3) откройте query tool
4) скопируйте текст файла schema.sql и вставьте в qeury tool, нажмите выполнить
5) проверьте что появилось 10 таблиц
6) повторите с файлом data.sql - он заполнит бд тестовыми данными

Если БД уже была создана раньше и вход не работает (логин/пароль верные, но «Неверный логин или пароль»):
7) выполните fix_passwords.sql в query tool — пароли в БД будут приведены к SHA-256, как в коде.

Тестовые учётные записи:
  admin / admin123  (администратор)
  petrov / 123456   (клиент)

Запуск приложения (из папки FuneralApp):
  javac -cp lib/postgresql-42.7.12.jar -encoding UTF-8 -d out src/Main.java src/ui/*.java src/dao/*.java src/models/*.java src/utils/*.java src/db/*.java
  java -cp "out;lib/postgresql-42.7.12.jar" Main

Кириллица в консоли: запускайте из cmd/PowerShell без chcp 65001 (стандартная кодировка Windows).
Не смешивайте chcp 65001 с обычным запуском — будет «кракозябры».
Поиск услуг (п. 4) работает при вводе на русском в той же консоли.
